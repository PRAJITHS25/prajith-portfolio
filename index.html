My Projects

AutoCraft – Playwright Test-Code Generation Tool

A Windows desktop application built with Python and Tkinter that simplifies Playwright test automation by recording browser interactions and generating pytest-compatible automation test code. AutoCraft provides a guided workflow for defining test cases, recording browser actions, reviewing generated code, and saving reusable Playwright tests.

  • Python
  • Playwright
  • Pytest
  • Tkinter
  • Test Automation
  • Code Generation
  • GitHub

Key Features

Browser interaction recording with Playwright Codegen, automatic test-code generation, test-case validation, duplicate test detection, integrated Python code editing, syntax highlighting, configurable Playwright options, screenshot capture on failure, trace capture, and authenticated session support.

Automation Workflow

Users provide the target URL and test-case details, launch Playwright Codegen to record browser interactions, review the generated automation steps, and save the resulting pytest-compatible test case for execution.
