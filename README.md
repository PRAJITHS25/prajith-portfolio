##  Automation Approach

The tests are structured using the **Page Object Model (POM)** to separate page-specific locators and actions from test scenarios.

```text
Test Cases
    ↓
Page Objects
    ↓
Locators & Actions
    ↓
Assertions
    ↓
Test Results
```

This approach improves:

* Maintainability
* Reusability
* Readability
* Scalability of the automation framework
